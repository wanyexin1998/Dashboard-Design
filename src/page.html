01 / DESIGN LANGUAGE

统一底色，让数据成为重点。

以下为本模板的参考参数，可在正式设计中调整。

PALETTE / 色彩角色

深色
浅色

深色与浅色共用一套语义 token；浅色逐项选定，而非反相。
选中态同时使用颜色、位置与文字。
状态色（绿 / 琥珀 / 红）只表达好坏与状态，不作系列色。

HIERARCHY / 阅读层级

  • 主指标28 px / 600
  • 类别与数值12–14 px
  • 辅助标签10–11 px
  • 卡片圆角 / 内边距18 / 24 px

MOTION / 状态过渡

  • 响应方式就地反馈
  • 数据更新图形与数字同步
  • 范围切换保留空间参照
  • 主题切换颜色 320ms 过渡，保留状态
  • 指标数字700ms 计数，单位不滑动
  • 减少动态效果直接呈现结果
02 / INTERACTION PRINCIPLES

每一种变化，都有清楚的含义。

01　看见局部，保留整体

悬浮数据项查看读数浮层；点击数据项或图例聚焦，再次点击或按 Esc 取消。柱形和环形会弱化其他项，占比条保留各段颜色。切换时间范围后清除旧选择。

02　直接操作，实时回应

沿时间线拖动探查状态，上下拖动目标线改变阈值。目标取 2,000–10,000 步，以 100 步递增；达到或超过目标均计为达标。

03　让交互有替代方式

聚焦数据项即可查看读数；面积图和折线图支持左右键探查。窄屏点选后在图下查看详情；时间游标支持左右键，目标线支持上下键。重播恢复示例的初始状态。“减少动态效果”保留操作反馈并跳过过渡。

03 / METRIC RULES

先说清是什么，再说好不好。

指标卡与指标面板共用一套数字格式、涨跌语义与判定规则。

FORMAT / 数字格式

  • 金额 ≥ 1 万 / ≥ 1 亿1,286.4 万 · 1.15 亿
  • 计数2,418 · ≥ 1 万写 4.8 万
  • 比率 / 比率之差38.4% · +1.2pp
  • 负数 / 空值−3.5%（U+2212）· — 并写原因
  • 同一张卡的金额按最大值统一单位
  • 卡面 / 读数浮层简写 / 全值

POLARITY / 涨跌语义

  • 箭头表方向 ↑ ↓ →
  • 颜色表好坏：绿向好 · 红向差
  • 减少为好退款率下降显示为绿
  • 中性指标只标方向，不着色
  • |变化| < 0.05持平
  • 对比口径最多两个：环比 + 同比

STATUS / 判定

  • 累计型（营收、订单）达成率 vs 时间进度
  • 超前 / 持平 / 滞后差 ≥ 0.5pp 才算超前或滞后
  • 阈值型按原始值判档
  • 状态胶囊图标 + 文字 + 颜色
  • 主数值始终是当期，不随悬浮
  • 未满周期浅色虚线，或改用日均
04 / QUERY RULES

条件从哪来，就回到哪去。

筛选、页签与表格共用一份筛选状态、一套地址序列化和同一组单元格语法。

FILTERS / 筛选

  • 生效单控件即时 · 抽屉批量应用
  • 时间全页只定截至日 · 卡内定口径
  • 单击图表选中 + 联动 · 看板级开关默认开
  • 联动与筛选取交集，来源图不过滤自己
  • 级联全路径匹配
  • 空结果写原因 + 三条出路

TABS / 页签

  • 页面级 / 卡内下划线 / 药丸
  • 切内容 / 切参数页签 / 分段控件
  • 激活内容在页内即切 · 要取数按 Enter
  • 层级最多两层
  • 放不下滚动 + 渐隐 + 更多菜单
  • 地址#!t01=trend&f04=…

TABLES / 表格

  • 数值右对齐，表头也右对齐
  • 排序默认 → 降序 → 升序 → 默认
  • 行点击只读 / 下钻 / 勾选 / 联动
  • 列组真跨列 + headers 关联
  • 长表≤ 50 行整表，超出 20 行分页
  • 合计由显示值相加，不手填
