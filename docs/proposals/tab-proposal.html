Tab 组件方案

为图表实验室梳理「切换」这件事：什么时候用页签、什么时候只是一个分段控件、什么时候根本不该切换。对照 W3C ARIA APG 与 Carbon、Polaris、Fluent、Radix、Ant Design、Semi、Vercel Geist 的公开文档，以及 Quick BI、FineBI、Power BI、Grafana、Looker Studio、GA4 的做法，归纳出 6 种需要新增的页签形态、一张选择表和一套无障碍约定；与已实现组件重叠的三项已并入现有组件或改为规则。

01 / Summary

先说结论

「切换」有两种：换看什么（内容区，用 tabs）和换怎么看（一个参数，用分段控件）。模板里这两种都已经出现，但语义没有分清楚——这份方案先把边界划出来，再补齐形态。

已拍板 · 6 项

  • 范围：六种一次做完
  • 激活：内容在页内聚焦即切，要取数按 Enter
  • 样式：页面级下划线，卡内药丸
  • 分段控件：保持按钮组语义

刻意不做

  • 用页签放需要互相比较的内容
  • 页签套页签（超过两层）
  • 把筛选条件做成页签
  • 页签当路由跳转用
  • 切换时内容高度跳动

05 / Decision tree

选哪一个

先问三句话，再决定用哪个控件；这三句话也是评审时的检查口径。

三问

一问：切换之后，下面是一块独立的内容区吗？
是 → 页签（tablist / tab / tabpanel）。
否，只是换了一个参数（周 / 月 / 年、实际 / 预算） → 分段控件（radiogroup 或 aria-pressed 按钮组）。
二问：这些内容需要放在一起比较吗？
需要 → 不要用页签，改成并排卡片或表格列组（Carbon：「Tabs should not be used if the user needs to compare information」）。
三问：它们有先后顺序、后一步依赖前一步吗？
有 → 用步骤条，不用页签（Carbon）。
目的地是另一个页面、有独立 URL 与数据模型 → 用二级导航，不要用页签伪装路由（Vercel Geist）。

角色映射

场景角色键盘

同一副外观（药丸）既可能是 tab 也可能是 radio——由它切什么决定，不由长相决定。Carbon 的 Content Switcher 长得像分段控件，但因为它切的是下方独立内容区，官方实现用的是 tablist / tab。

06 / Rules

统一规范

尺寸、动画、溢出、URL 与无障碍，一次定清楚，后面的页签都照这个长。

尺寸与外观

  • 下划线页签：文字 12.5px，选中加粗 600，指示条 2px、圆角 2px、色为 --s-blue；页签间距 22px；底线 --c-divider。
  • 药丸页签 / 分段控件：轨道 --c-control、圆角 20px、内边距 3px；选中为反色 --c-inverse；分段控件文字 10px，药丸页签 11.5px。
  • 指标页签（T03）：卡片式，圆角 12px，选中底 --c-inset + 顶部 2px 指示条；数值 20px / 600。
  • 纵向页签：宽 118px，选中左侧 2px 指示条 + --c-inset 底。
  • 数量上限：桌面一行 5–7 个，窄屏 3–4 个，超出走 T06（Vercel Geist 的经验值）。

切换动画

  • 内容在同一坐标系里的（同一张图换指标）→ 原位变形 650ms，沿用模板「范围切换不重画」。
  • 内容结构不同的（换成表格 / 换成另一组卡片）→ 指示条移动 200ms + 内容淡入 160ms，不做位移动画。
  • 面板高度固定或设最小高度，避免切换时页面跳动。
  • 减少动态效果：指示条直接到位，内容直接显示。

溢出与深链接

  • 溢出优先横向滚动 + 边缘渐隐提示，两端给箭头；方向键移动焦点时自动把目标滚进可视区（Carbon）。
  • 页签由数据生成、数量不可控时，才上「更多 ▾」折叠菜单（Ant Design 支持带搜索的更多菜单）。
  • 选中页签写进 URL hash（#t=main:trend，D6），刷新与分享复原；与筛选方案共用一套序列化。
  • 层级上限两层：页面级页签 + 卡内分段控件（第一版的 T09）。Grafana 不允许 Tab 直接嵌 Tab，Looker Studio 页面层级也设了上限。
  • 带数值的页签只有 P03 一种：页签即指标卡、驱动下方图表；其余页签一律只放文字，最多带计数徽标（T05）。

07 / Integration

并入模板的方式

模板里已经有分段控件与指标页签，这一步主要是统一语义并补形态。

  • 新分组「切换与导航」：下划线页签、药丸页签、溢出页签、徽标页签、纵向页签、动态页签各一张样本卡；分段控件与指标页签不另立样本，直接指向已有的卡（柱状图、P03）。
  • 新增 TabKit：tabs(container, {activation}) 建立 tablist / tab / tabpanel 关系与 roving tabindex；group(container) 处理 radiogroup / 按钮组语义；overflow() 处理滚动、箭头与「更多」菜单；link() 同步 URL hash。
  • 语义校准：模板现有的 .segmented（周 / 月 / 年、实际 / 预算、本月 / 本季 / 本年）保持 aria-pressed 按钮组语义，不改成 tab；P03 指标页签保持 tablist 语义并补 tabindex 管理（已实现）。
  • 复用现有能力：分段控件样式与主题 token、ChartKit.animate 的原位变形、减少动态效果、读数浮层。
  • 文档：md 文档新增「切换与导航」章节，并在第 3 节交互系统里补一条「切内容用 tab，切参数用按钮组」的总则。
