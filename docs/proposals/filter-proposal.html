01 / Summary

先说结论

筛选器回答的是「看哪一段数据」。十一项覆盖「定时间 → 收范围 → 看清楚选了什么 → 能退出去」这条完整链路，本轮一次做完。

本轮范围 · 十一项一次做完

  • 时间：F01 快捷时间 · F02 日期区间 · F11 日期面板
  • 维度：F03 单选 · F04 多选 · F05 级联 · F06 chips
  • 看板：F07 已选回显 · F08 抽屉 · F09 联动 · F10 结果条

F07 与 F10 是最容易被省掉、也最容易让人「看错数」的两项；F11 是时间上下文的总开关。

已拍板 · 9 项

  • 生效：单控件即时，抽屉批量应用
  • 时间：全页定截至日，卡内定口径
  • 单击图表：直接联动 + 看板级开关（默认开）
  • 级联：全路径匹配
  • 日期面板：状态点，星期加权
  • 筛选与页签状态写进 URL hash
  • 外观：输入框方角，选项药丸

与推荐不同的两项：首批范围（改为一次做完）、单击图表（改为直接联动），代价与落地方式见第 07 节。

刻意不做

  • 把筛选塞进下拉菜单里藏起来
  • 一屏超过 6 个全局筛选器
  • 筛完不告诉你「筛掉了多少」
  • 空结果只给一句「暂无数据」
  • 联动与筛选互相覆盖而不是取交集

前两条来自 Carbon 的筛选模式，后三条来自本次调研里公认的缺口。

05 / Rules

统一规范

一份筛选状态、一套控件语法、一套交互与无障碍约定。筛选器不产生数据，只产生「当前条件」，所有读数由它派生。

筛选状态契约

// 一个看板 = 一份 FilterState；控件只读写它
{
  "time": { "preset": "month",        // 快捷项 id，自定义为 null
             "from": "2026-09-01", "to": "2026-09-22",
             "grain": "day",          // day | week | month
             "compare": "mom" },      // mom | yoy | none
  "dims": [
    { "id": "region", "label": "区域",
      "mode": "multi",            // single | multi | cascade
      "values": ["华东","华南","华北"],
      "paths": null,               // 级联时写全路径
      "total": 6 },                // 候选总数，用于「3 / 6」
    { "id": "channel", "label": "渠道", "mode": "multi", "values": [] }
  ],
  "link": { "source": "chart-bars",  // 图表联动的来源组件
             "dim": "region", "value": "华东" },
  "applied": true,                  // 批量模式下是否已提交
  "result": { "rows": 22, "of": 30 }   // 结果条与空态用
}

筛选与联动取交集（腾讯云 BI 的做法），不互相覆盖；URL hash 序列化这份对象即可分享与刷新复原。

控件语法

场景控件语义

尺寸与外观

  • 控件高 30px、圆角 8px、描边 --c-outline；chips 高 27px、圆角 14px；弹层圆角 12px + --c-shadow。
  • 选中态用反色（--c-inverse），不是主色，和模板的分段控件保持同一套选中语法。
  • 筛选条与卡片同宽、贴在卡片网格上方；页面滚动时吸顶，高度 52px。
  • 一屏最多 6 个全局筛选器，超出收进 F08 抽屉。

06 / Integration

并入模板的方式

不改现有 29 个组件，只新增一层「筛选状态」与一组控件。

  • 新分组「筛选与查询」：F01–F11 各一张样本卡；控件类样本半宽，日期面板、抽屉与联动组合演示跨两列。
  • 日期面板接「截至日」：选中某天 = 设定全页的截至日，K04 / K05 / K09 / P02 等按该日重算月 / 季 / 年累计（D3）。
  • 新增 FilterKit：state() 读写筛选状态、chips() 生成已选回显、popover() 统一弹层定位与焦点陷阱、combobox() / listbox() 两套键盘模型、serialize() 与 URL hash 互转、summary() 产出结果条文案。
  • 复用现有能力：分段控件样式、--c-panel 弹层色、读数浮层的定位算法（浮层与弹层共用一套边界夹紧）、减少动态效果、主题 token。
  • 与指标组件的接口：筛选状态变化 → 触发各卡 update(state)（新增可选钩子，未实现的卡忽略），数值走 KpiKit.count 插值，不清空重画。
  • 文档：视频图表设计蒸馏.md 增加「筛选与查询」章节，规格写法与第 4 节一致；验收同样跑深 / 浅 × 三档宽度 + 键盘路径。
