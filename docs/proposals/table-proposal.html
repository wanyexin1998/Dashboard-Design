01 / Summary

先说结论

看板里的表格不是「数据库浏览器」，是兜底的明细层：图回答趋势与结构，表回答「具体是哪一行、差多少」。所以先做排版与单元格语法，再做能力。

  • B01 明细表　B07 对比列组
  • B03 交叉表　B05 分组小计　B06 可展开行
  • 规则 单元格语法、三态排序、五态 —— 从 P05 / K08 / K01 抽出来统一

记分卡表就是 P05，排行表就是 K08，不再新做；P05 改用 TableKit，外观不变。

已拍板 · 7 项

  • 范围：五种一次做完
  • 排序：三态，P05 同步
  • 分隔线为主，长表才开斑马纹
  • 条件格式：数据条 + 状态胶囊
  • 行点击：可配置，不写死
  • 列组：真跨列表头（colspan）
  • ≤ 50 行整表，超出分页

与推荐不同的三项：范围、行点击、列组表头，代价与落地方式见第 08 节。

刻意不做

  • 虚拟滚动（看板级数据量用不上）
  • 列拖拽、列宽拖拽、列设置面板
  • 斑马纹 + 网格线同时开
  • 色阶 + 数据条 + 胶囊三层颜色叠加
  • 只靠 colspan 让读屏去猜表头

最后一条来自 Adrian Roselli：主流读屏对跨列表头的推断互相矛盾，所以真跨列时一律写 headers 显式关联。

06 / Rules

统一规范

排版、交互、无障碍三块；能落到代码里的都写成具体数值。

排版

  • 行高 34px（密集）/ 38px（默认），表头与数据行同高；字号 11.5px，表头 10px。
  • 默认用水平分隔线（--c-divider）+ 悬浮高亮（--c-hover），不同时开网格线；行数 > 20 且列数 ≥ 6 时自动开斑马纹（--c-inset，D3）。
  • 数值列右对齐 + 等宽数字，表头跟着列内容右对齐；文本列左对齐；不要居中。
  • 列宽固定（table-layout: fixed），长文本截断 + title 全名，避免切换数据时列宽跳动。
  • 合计行放最后，--c-inset 底 + 加粗 + 上分隔线；小计行用 60% 浓度的同一底色。
  • 一张卡最多一张表；表放在章节末尾兜底，不与图争第一屏。

交互

  • 排序：三态（默认 → 降序 → 升序 → 默认，D2 已定，P05 同步）；排序列用箭头填充 + 文字加粗标识，不只靠颜色；一次只有一列排序。
  • 行悬浮 / 聚焦高亮整行，读数浮层给这一行的算式与口径（沿用模板的读数浮层）。
  • 排序动画：FLIP 位移 420ms；减少动态效果时直接重排。
  • 行点击：rowAction 按表配置（D5）—— inspect / drill / select / filter，一张表只取一种主动作；展开按钮与复选框始终是独立控件。
  • 列组：真跨列两行表头（D6），每个数据格写 headers 显式关联。
  • 窄屏：容器横向滚动，首列 sticky；滚动容器 tabindex=0 + role=region，键盘可进入并用方向键滚动。

07 / Integration

并入模板的方式

模板已有记分卡表（P05），这一步是把它抽象成可复用的一层。

  • 新分组「表格与明细」：明细表、对比列组、分组小计、可展开行、交叉表各一张样本卡，均跨两列；记分卡与排行不另立样本，直接指向 P05、K08。
  • P05 改用 TableKit：记分卡表作为 TableKit 的第一个使用者，外观不变，只把渲染、排序、单元格换成共享实现；排序改为三态（D2）。
  • 新增 TableKit：render(container, {columns, rows, total}) 按列定义渲染并套用 KpiKit 的格式；sort() 管三态与 aria-sort + FLIP；cells 提供 bar / delta / status / mini 四种单元格渲染器；scrollRegion() 处理窄屏滚动容器的无障碍属性。
  • 复用现有能力：读数浮层（行级读数）、状态色与 --st-*-soft 胶囊、数字格式、K01 的五态模型（含「数据延迟」）、主题 token、减少动态效果。
  • 与筛选 / 页签方案的接口：筛选状态变化 → 表重排并更新合计行；页签切换 → 同一张表换列定义（原位变形不适用于表格，走 160ms 淡入）。
  • 文档：md 文档新增「表格与明细」章节，含列类型表与无障碍清单；验收跑深 / 浅 × 三档宽度 + 键盘排序路径。
