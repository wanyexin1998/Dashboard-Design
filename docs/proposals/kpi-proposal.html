指标卡与指标面板方案

为图表实验室新增「指标与概览」分组做的调研与方案。对照约 28 个国际 BI、中文 BI、组件库与产品看板，归纳出 10 种指标卡、7 种指标面板，并与你的 BI Visual DNA（KPI 家族、目标与进度家族）逐项对齐。下方草图为静态示意，右上角可切换深 / 浅两套 token 查看；确认范围后再并入模板。

方案阶段 · 未改动基准模板 · 草图数据为示例，派生值由同一数据源计算

01 / Summary

先说结论

首批八项覆盖「现在多少 → 比以前如何 → 能否完成」三问，正好对应你 DNA 里的目标管理四件套：目标、达成、差距、时间进度。

建议首批 · P0

  • K01 数值卡　K02 对比卡　K03 趋势卡
  • K04 目标进度卡（含时间进度虚线）
  • K05 进度环卡（月蓝年橙）
  • P01 指标条　P02 主次面板
  • P03 指标页签驱动图表

K04 / K05 是你 DNA 的签名组件；P03 把指标卡和现有 15 个图表连起来。

需要你拍板 · 6 项

  • 首批范围
  • 涨跌配色（好坏色 vs 涨红跌绿）
  • 数字单位（万 / 亿 vs K / M）
  • 命名：现有悬浮层也叫"指标面板"
  • 外观走模板语言还是 DNA 白卡
  • 悬浮迷你图时主数值是否跟随

每项都附了推荐默认，见第 07 节。

刻意不做

  • 水波、3D、发光等大屏装饰
  • 每个数字配一个图标
  • "目标"与"当期"同色
  • 无上限的对比口径（最多两个）
  • 只靠颜色表达涨跌或状态

前四条来自你的 DNA 反模式清单，最后一条来自无障碍要求。

对比最多两个。Quick BI 上限 2、Metabase 与 Mixpanel 上限 3；主对比（环比 / 同期）加一个次对比（同比）已覆盖绝大多数经营场景。
方向要显式声明。Power BI、Datadog、Tremor、Tableau Pulse 都有"增加为好 / 减少为好"开关；中文 BI 只提供"颜色翻转"，没有按指标方向识别。数据契约里放 polarity。
颜色表好坏，箭头表方向。Quick BI 默认 >0 绿、<0 红，与你 DNA 的"绿 = 向好、红 = 向差"一致；证券的涨红跌绿是另一套语义，不混用。
中文单位是标配。Quick BI、FineBI、观远、腾讯云 BI 都有万 / 亿；国际工具用 K / M / B。默认万 / 亿。
空值与零值分开。Looker 提供"无数据 / 0 / - / 空白"多种显示，网易有数分别设置空值与零值样式。空值显示"—"并说明原因，零值照常显示 0。
四种状态等高。Stripe 的加载、错误、空、正常四态保持同一高度避免跳动；Tableau Pulse 在当期为空时提示"可能延迟"。再加一个"数据延迟"态。
数字动画要克制。Arco 内置 countUp（默认 2000ms），Ant Design 借 react-countup；模板已有"数字同步"，时长压到 700ms，并用等宽数字防止宽度抖动。
阈值按原始值判断。Datadog 的条件格式看原始值而不是缩写后的显示值；96.44% 不能因为显示成 96.4% 就换档。
口径就近可查。GA4 摘要卡悬浮标签显示指标定义；卡片标签旁放 ⓘ，悬浮或聚焦显示口径、统计区间、更新时间。
面板用页签驱动图表。GA4、Vercel、Stripe 都是"上方一排指标，下方一张图"；这是把指标卡和现有 15 个图表接起来最自然的方式。

05 / Rules

统一规范

所有类型共用一份数据契约、一套数字格式与涨跌语义；派生值（达成率、差额、对比、状态）一律由组件计算，不手填。

数据契约

// 一个指标 = 一个对象；卡片与面板都只接收它
{
  "id": "revenue_mtd",
  "label": "本月营收",
  "note": "确认收入，按签收日；不含退款",   // ⓘ 口径
  "unit": "元",
  "format": { "type": "currency", "compact": "auto", "precision": 1 },
  "value": 12863760,
  "period": { "label": "9 月 1–22 日", "grain": "day",
              "partial": true, "elapsed": 22, "total": 30 },
  "compare": [                                 // ≤ 2 个
    { "kind": "mom", "label": "环比（同期）", "base": 11845083 },
    { "kind": "yoy", "label": "同比", "base": 10604913 }
  ],
  "target": { "value": 18000000, "label": "月目标" },
  "polarity": "up",                           // up | down | neutral
  "thresholds": null,                          // [{ "min": 0.98, "status": "good" }, …]
  "series": [{ "t": "2026-09-01", "v": 557000 }, …],
  "updatedAt": "2026-09-22T09:30:00+08:00",
  "freshness": "PT6H"                         // 超时显示"数据延迟"
}

尺寸与主题

  • 卡片最小宽 200px；高度三档 112 / 132 / 168（单值 / 带图 / 带明细），同行等高。主数值 30px，面板主指标 44px，标签 12px，对比 11px；超过 7 位先降字号（30→26→22）再升单位，不溢出。
  • 颜色全部走图表主题 token：好坏用 --st-good / --st-bad（文字用其 -text 变体），迷你图与进度用系列色，轨道 --c-track，时间进度虚线用 --st-bad（沿用 DNA 的红色虚线）。深 / 浅两套已在模板里定义，无需新增系列色。
  • 状态色 --st-* 只用于好坏与状态，不作为系列色；珊瑚色（仪表 NORMAL）与向差红在同一屏时，靠图标与文字区分。

06 / Integration

并入模板的方式

不改现有 15 个图表，只新增一个分组与一组模块。

  • 新分组「指标与概览」：筛选条新增按钮与计数；每种指标卡一张样本卡，内含 2–3 个变体（如 K02 同时展示向好与向差）；面板类样本跨两列。
  • 新增 KpiKit：format()（万 / 亿、pp、真减号、空值）、compare()（对比与好坏判定）、spark()、progress()、statusOf()（按原始值判档）；每种类型一个 ChartDemos.kpi_* 模块，只接收数据契约对象。
  • 复用现有能力：ChartKit.animate（数字同步）、ChartInspector（对比基期、计算式进读数浮层）、图表主题 token、减少动态效果、重播、键盘约定。
  • 文档：视频图表设计蒸馏.md 新增「指标组件」章节，逐类型写法与第 4 节一致；验收同样跑深 / 浅 × 三档宽度。

07 / Decisions

需要你拍板的六件事

每项给出推荐默认；你没有异议的项，按推荐执行。

D1首批范围

  1. P0 八项：K01–K05 + P01–P03
  2. 全部十七项一次做完
  3. 只做指标卡，面板下一轮

八项已覆盖目标管理四件套；其余类型依赖同一套 KpiKit，后续增量很小。

D2涨跌配色

  1. 颜色表好坏：绿 = 向好、红 = 向差，按 polarity 判断
  2. 涨红跌绿（证券惯例）
  3. 提供全局开关

推荐项与你的 DNA、Quick BI 默认一致；退款率这类逆向指标下降显示为绿。

D3数字单位

  1. 中文单位：万 / 亿
  2. K / M / B
  3. 两者可切换

中文 BI 普遍采用万 / 亿；若模板要给海外同事看，再加切换。

D4命名

  1. 新组件叫「指标面板」，现有悬浮层改称「读数浮层」
  2. 新组件改叫「指标组」，悬浮层保持原名

页面文案里"悬浮查看指标面板"指的是悬浮层；推荐项只改文案，代码里的 ChartInspector 不改名。

D5外观

  1. 沿用模板语言：18px 圆角、英文眉标、柔和系列色
  2. 采用 DNA：8px 白卡、居中标题、渐变柱
  3. 做成可切换皮肤

模板是组件样本库，保持一种语言更利于比较；DNA 皮肤可在正式看板里通过 token 套用。

D6悬浮迷你图时主数值是否跟随

  1. 不跟随：主数值保持当期，读数写在迷你图旁
  2. 跟随：主数值临时显示悬浮日的值

跟随式在 Stripe 一类产品里常见，但容易把历史值误读成当前值。
