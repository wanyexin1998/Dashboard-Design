# 示例数据的生成脚本（留档）

页面里的示例数据是固定事实，已经写进源码：指标模块的 `DATA` 在 `src/kpi/kpi1.js`，筛选 / 页签 / 表格模块的 `FACT` 在 `src/ftt/ftt0.js`。这里的脚本记录这些数字是怎么来的，**构建不会运行它们**。

| 脚本 | 产出 | 写进 |
|---|---|---|
| `gen_kpi_daily.py` | 9 月逐日订单与退款（按逐日营收和约 5,320 元的客单价反推，合计精确等于 2,418 单） | `DATA.daily` |
| `gen_kpi_monthly.py` | 1–9 月月度营收、订单、退款、毛利率与及时率 | `DATA.monthly` |
| `gen_ftt_facts.py` | 大区 × 日、大区 × 渠道、渠道 × 客群等事实表（整数 0.1 万元 / 整数单，边际精确相加） | `FACT` |

改数据时：改脚本 → 重新生成 → 把输出贴回源码 → `npm run build` → `npm test`（两个模块加载时的 `check()` 勾稽会在控制台报出对不上的地方）。
